# Plaque

**나만의 미술관 스크랩북.**

전시장에서 만난 작품을 사진으로 남기고, 감상과 평점을 기록하는 개인 아카이브 앱. 공유하는 앱이 아니라, 자신에게 말 거는 앱.

---

작품 사진을 찍으면 원근이 자동으로 보정돼요. 제목·작가·연도·재료·전시·갤러리·방문일·평점·태그·감상 메모를 함께 남길 수 있고, 날짜순이나 평점순으로 정렬하거나 전문 검색으로 찾아볼 수 있어요. Google 계정으로 로그인하면 어느 기기에서든 컬렉션이 이어져요.

---

## 기술 스택

Next.js · TypeScript · Tailwind CSS v4 · Supabase · OpenCV.js · Vercel

원근 보정은 OpenCV.js로 브라우저 안에서 처리해요. AI API는 사용하지 않아요.
